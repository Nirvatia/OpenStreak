# Макет «Штамп»

Источник: канвас Claude Design «OpenStreak — Волк концепт», страница «Б · Штамп — полная версия»
(<https://claude.ai/artifact/NijsZRV7tXgTrtd9D6sVWe>). Здесь лежит копия исходников этой страницы
на 4 ноября 2026 — чтобы макет был под рукой при разработке. Если макет меняется, правьте его
на канвасе и обновляйте копию.

Файлы — `.dc.html` (формат Claude Design): разметка с inline-стилями и данные примера в
`renderVals()`. Сами по себе в браузере не открываются — их читают как спецификацию:
размеры, отступы, цвета, тексты.

| Файл                                      | Экран                                    |
| ----------------------------------------- | ---------------------------------------- |
| `B-Today` / `N-Today`                     | Сегодня (светлая / тёмная)               |
| `B-Tasks` / `N-Tasks`                     | Задачи                                   |
| `B-Habits` / `N-Habits`                   | Привычки                                 |
| `B-Goals` / `N-Goals`                     | Цели                                     |
| `B-Stats` / `N-Stats`                     | Статы и звание                           |
| `B-TaskSheet` / `N-TaskSheet`             | Новое дело (шторка)                      |
| `B-Review` / `N-Review`                   | Итог дня                                 |
| `B-Settings` / `N-Settings`               | Настройки                                |
| `BNav` / `NNav`                           | Таб-бар                                  |
| `B-Kit`                                   | Стиль: палитра, шрифты, печати, иконки, волк, тон |
| `N-Kit`                                   | Палитры обеих тем и проверка контраста   |

Цвета из макета перенесены в `src/theme/palettes.json` — источник правды для кода.
Свойство `ink` в макетах — выбираемый цвет чернил: красный `#C8102E`, синий `#1F3FA8`, чёрный `#151515`.
