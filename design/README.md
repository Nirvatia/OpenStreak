# Макеты

## «Луна» — текущий дизайн

Источник: канвас Claude Design «OpenStreak — Волк концепт», страница «Луна — полный макет»
(<https://claude.ai/artifact/NijsZRV7tXgTrtd9D6sVWe>). В `luna/` — копия её исходников. Если макет
меняется, правьте его на канвасе и обновляйте копию.

Файлы — `.dc.html` (формат Claude Design): разметка с inline-стилями и данные примера в
`renderVals()`. Сами по себе в браузере не открываются — их читают как спецификацию.

- `L-*.dc.html` — экраны и компоненты, тема задаётся пропом `theme` (`night` по умолчанию)
- `R-*.dc.html` — те же экраны в теме «Рассвет» (обёртки с `theme="dawn"`)
- `canvas.json` — расположение артбордов на канвасе (все страницы, включая отвергнутые варианты)

| Файл                         | Что                                                    |
| ---------------------------- | ------------------------------------------------------ |
| `L-Today`                    | Сегодня: луна дня, «Осталось» и «Сделано» журналом     |
| `L-Tasks`                    | Дела: долги / сегодня / завтра                         |
| `L-Habits`, `L-Habit`        | Привычки: неделя лунами; карточка с месяцем и сериями  |
| `L-Goals`                    | Цели-договоры                                          |
| `L-Pack`                     | Стая: звание, очки, неделя                             |
| `L-NewSheet`                 | Шторка «Новое»: дело / привычка / цель                 |
| `L-Review`, `L-Closed`       | Итог дня (оценка фазой луны) и «День закрыт»           |
| `L-Settings`                 | Настройки                                              |
| `L-Kit`                      | Стиль: палитры, шрифт, иконки, луна, волк, форма, цитаты |
| `L-Icon`, `L-Moon`, `L-Wolf` | Компоненты: гранёная иконка, луна, волк                |
| `L-Notches`, `L-Nav`         | Компоненты: зарубки (только в карточке привычки), таб-бар |

Главные правила стиля — на листе `L-Kit` и в `ROADMAP.md` («Принятые решения»).
