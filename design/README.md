# Макеты

## «Мульт» — текущий дизайн

Источник: канвас Claude Design «OpenStreak — Мульт концепт»
(<https://claude.ai/artifact/JRp1pkCA5mxnbNUjFAF5v3>). В `mult/` — копия его исходников. Если макет
меняется, правьте его на канвасе и обновляйте копию.

Файлы — `.dc.html` (формат Claude Design): разметка с inline-стилями и данные примера в
`renderVals()`. Сами по себе в браузере не открываются — их читают как спецификацию.

- `M-*.dc.html` — экраны и компоненты в теме «День», тема задаётся пропом `theme` (`day` / `night`)
- `M-*-Night.dc.html` — те же экраны в теме «Вечерний мульт» (обёртки с `theme="night"`);
  исключение — `M-Closed` (по умолчанию вечер) и `M-Closed-Day`
- `Main.dc.html` — лист стиля: палитры, шрифты, кнопки, плашки, луна, волк, таб-бар
- `canvas.json` — расположение артбордов на канвасе

| Файл                     | Что                                                                  |
| ------------------------ | -------------------------------------------------------------------- |
| `M-Today`                | Сегодня: луна дня с очками, волк с цитатой, «Осталось» и «Сделано»   |
| `M-Tasks`                | Дела: группы плашками, свайп «вычеркнуть», тост «Вернуть»            |
| `M-Habits`, `M-Habit`    | Привычки: неделя лунами, бейджи серий; карточка — +10/+20, зарубки   |
| `M-Goals`                | Цели-договоры                                                        |
| `M-Pack`                 | Стая: звание, лестница званий, неделя, числа                         |
| `M-New`                  | Шторка «Новое»: дело / привычка / цель                               |
| `M-Review`, `M-Closed`   | Итог дня (оценка луной, вердикт волка) и «День закрыт»               |
| `M-Settings`             | Настройки                                                            |
| `M-Icon`, `M-Icons`      | Иконка (все 60 рисунков) и лист иконок                               |
| `M-Moon`, `M-Wolf`, `M-Nav` | Компоненты: луна, волк, таб-бар                                   |
| `M-AppIcon`, `M-IconArt` | Иконка приложения: три варианта (выбран Б — волк на жёлтом)          |
| `M-Splash`               | Сплэш днём и вечером (`M-Splash-Night`)                              |

Главные правила стиля — на листе `Main` и в `ROADMAP.md` («Принятые решения»).
