# Дорожная карта OpenStreak

Цель — релизная версия для **Android, iOS и ПК** с собственным дизайном «Штамп», темами,
своим набором иконок, тремя языками и синхронизацией между устройствами.

Статусы: ✅ готово · 🔨 в работе · ⏳ впереди · ❓ ждёт решения

---

## ✅ Этап 0. Порядок в проекте

- Зависимости выровнены на одну версию Expo SDK (57), `npm ci` снова работает
- Удалены мусорные файлы, README переписан
- ESLint, Prettier, Jest, GitHub Actions (типы, линтер, формат, тесты, контраст)
- Палитры тем в `src/theme/palettes.json` + автопроверка контраста по WCAG для обеих тем

## ✅ Этап 1. Новое ядро данных

- Модель данных v2 (`src/core`): `id` / `createdAt` / `updatedAt` / `deletedAt` у каждой записи,
  мягкое удаление — готово к синхронизации
- Отметки привычек, цели, отдых, итоги дня — отдельные записи; сущность «Место» для геозон
- Хранилище: SQLite (iOS/Android), AsyncStorage (веб), в памяти (тесты)
- Автоперенос данных старой версии, старая копия сохраняется как резерв
- Экспорт v5, импорт v5 и v4 с проверкой каждой записи
- Напоминания ставятся в систему заранее — приходят при закрытом приложении
- Исправлены баги: срывы в статистике, перелистывание месяца, мигание «Добро пожаловать»,
  смена суток при открытом приложении

## ⏳ Этап 2. Дизайн-система «Штамп»

- ❓ Переход на Expo SDK 58 (RN 0.88, gesture-handler 3) — до начала новых компонентов
- Веб-режим для разработки (`react-native-web`): проверять интерфейс в браузере на ПК
- Токены темы из `palettes.json`: светлая и тёмная, «как в системе», цвет чернил
- Шрифты: Oswald (заголовки) + Golos Text (текст), без лишних начертаний
- Свой набор иконок: SVG-исходники на сетке 24 / линия 2.5 / острые углы → генерация компонентов,
  иконки привычек, волк-печать в трёх состояниях
- Базовые компоненты: экран, заголовок, строка-чекбокс, печать, счёт палочками, чипы,
  сегментный переключатель, переключатель, кнопка-оттиск, шторка, таб-бар, тост с «Отменить»
- Каталог компонентов (отдельный экран в dev-сборке) для визуальной проверки

## ⏳ Этап 3. Новые экраны, настройки, языки

- Экраны по макетам: Сегодня, Задачи, Привычки, Цели, Статы, Новое дело, Итог дня
- Экран настроек: тема, чернила, «пацанский тон», звания и очки, язык, начало недели,
  время итога дня, места, бэкап
- Звания (Щенок → Волчонок → Волк → Вожак → Альфа) и очки
- Локализация ru / en / es, тон «пацанский / обычный» как отдельный набор строк
- Отмена удаления, свайпы на gesture-handler, без лишних перерисовок
- Удаление старых экранов и слоя совместимости (`store/appStore.ts`, `core/legacy.ts`)
- Иконка приложения и сплэш в стиле «Штамп»

## ⏳ Этап 4. Напоминания по месту

- Места: точка на карте или «где я сейчас», радиус, вход / выход
- Геозоны через `expo-location` + `expo-task-manager` (фоновая геолокация)
- Экран-объяснение перед запросом разрешения «Всегда»
- Ограничения: iOS — до 20 зон, Android — до 100; только телефоны; нужна dev-сборка

## ⏳ Этап 5. ПК и веб

- Веб-сборка как PWA (установка из браузера, работа офлайн)
- Обёртка Tauri для Windows / macOS / Linux
- Раскладка под широкий экран, горячие клавиши

## ⏳ Этап 6. Синхронизация

- Supabase: авторизация (e-mail, Google, Apple), Postgres, правила доступа к строкам
- Синхронизация изменений по `updatedAt` (побеждает последнее), мягкие удаления
- Работа офлайн, очередь изменений, индикатор синхронизации
- Координаты мест по умолчанию не уходят в облако

## ⏳ Этап 7. Релиз

- Имя пакета и владелец лицензии (сейчас в `LICENSE` — шаблон Expo)
- Профили EAS, подписи, OTA-обновления (`expo-updates`)
- Политика конфиденциальности, декларация фоновой геолокации для Google Play
- Материалы для сторов, бета-тест

## Принятые решения

| Решение                                                           | Почему                                                           |
| ----------------------------------------------------------------- | ---------------------------------------------------------------- |
| Остаёмся на Expo / React Native, без Flutter                      | Один код на Android, iOS и веб; переписывать на Dart нет смысла  |
| Local-first: данные на устройстве, синхронизация — отдельный слой | Работает офлайн; синхронизацию можно добавить без переделки ядра |
| Дизайн «Штамп»: бетон, чернила, печати, волк-печать               | Выбран из четырёх концептов; светлая и тёмная темы               |
| Контраст по WCAG обязателен для обеих тем                         | Проверяется скриптом в CI (`npm run check:contrast`)             |
| Языки ru / en / es                                                | По запросу                                                       |
