# Дорожная карта OpenStreak

Цель — релизная версия для **Android, iOS и ПК** с собственным дизайном «Луна», двумя темами,
своим набором иконок, тремя языками и синхронизацией между устройствами.

Статусы: ✅ готово · 🔨 в работе · ⏳ впереди · ❓ ждёт решения

## ⏳ Этап 4. Экраны, настройки, языки

Навигация по макету: вкладки **Сегодня · Дела · Привычки · Цели · Стая**. «Отсчёт» уходит —
его заменяют цели со сроком. Настройки открываются из шапки «Сегодня». Итог дня и
«День закрыт» — отдельные экраны.

- Сегодня: большая луна дня, строка «Запиши дело или привычку», «Осталось» и «Сделано»
  журналом со временем
- Дела (группы «Долги / Сегодня / Завтра», свайп «вычеркнуть»), Привычки (неделя лунами,
  вредные — чистые дни), карточка привычки (месяц лунами, зарубки, +10/+20, выходной, слив)
- Цели («договор»: зачёт, награда, «если слил», «слово дано»), Стая (звание, очки, неделя)
- Новое (шторка: дело / привычка / цель), Итог дня (оценка фазой луны), «День закрыт»
- Настройки в профиле (синхронизируются): тема Ночь / Рассвет / как в системе, пацанский тон,
  цитаты волка, звания и очки, язык, начало недели, время итога дня; места и бэкап
- Звания (Щенок → Волчонок → Волк → Вожак → Альфа) и очки — чистая логика в `core` с тестами
- Цитаты волка: свои, не чужие; одна в день, только в пацанском тоне, выключаются
- Локализация en / es для обоих тонов
- Отмена удаления (5 секунд), свайпы на gesture-handler, без лишних перерисовок
- Удаление старых экранов и слоя совместимости (`store/appStore.ts`, `core/legacy.ts`,
  `types/models.ts`, `theme/tokens.ts`), а с ними — `@gorhom/bottom-sheet` и Manrope
- Иконка приложения и сплэш: волк на полной луне

## Принятые решения

| Решение                                                            | Почему                                                                        |
| ------------------------------------------------------------------ | ----------------------------------------------------------------------------- |
| Остаёмся на Expo / React Native, без Flutter                       | Один код на Android, iOS и веб; переписывать на Dart нет смысла               |
| Local-first: данные на устройстве, синхронизация — отдельный слой  | Работает офлайн; синхронизацию можно добавить без переделки ядра              |
| Дизайн «Луна»: ночь и рассвет, фазы луны, гранёные иконки, волк    | «Штамп» оказался громоздким на телефоне; «Луна» — итог трёх раундов концептов |
| Без акцентного цвета, без «ИИ-примет» (капс, моно, антиква, срезы) | Цвет только со смыслом; приложение не должно выглядеть шаблонным              |
| Макет сначала смотрим на телефоне, потом переносим в код           | Иначе пропорции обманывают: на мониторе всё кажется меньше                    |
| Контраст по WCAG обязателен для обеих тем                          | Проверяется скриптом в CI (`npm run check:contrast`)                          |
| Языки ru / en / es                                                 | По запросу                                                                    |
