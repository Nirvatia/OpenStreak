# Дорожная карта OpenStreak

Цель — релизная версия для **Android, iOS и ПК** с собственным дизайном «Штамп», темами,
своим набором иконок, тремя языками и синхронизацией между устройствами.

Статусы: ✅ готово · 🔨 в работе · ⏳ впереди · ❓ ждёт решения

---

## ✅ Этап 0. Порядок в проекте

- Зависимости выровнены на одну версию Expo SDK (57), `npm ci` снова работает
- Удалены мусорные файлы, README переписан

## ✅ Этап 1. Новое ядро данных

- Исправлены баги: срывы в статистике, перелистывание месяца, мигание «Добро пожаловать»,
  смена суток при открытом приложении

## 🔨 Этап 2. Дизайн-система «Штамп»

Макет: `design/stamp/` (копия канваса, описание — `design/README.md`). Новые компоненты живут
в `src/ui/` и не зависят от старых экранов; старые экраны пока работают как есть.

- ✅ Переход на Expo SDK 58 (RN 0.88, React 19.3, gesture-handler 3, reanimated 4.7)
- ✅ Веб-режим для разработки (`react-native-web`): интерфейс в браузере на ПК, колонка шириной
  с телефон
- ✅ Макет перенесён в репо, нестыковки исправлены (переключатель темы, даты примеров)
- ✅ Токены темы из `palettes.json`: светлая, тёмная, «как в системе»; цвет чернил — красные /
  синие / чёрные (в тёмной — белые), каждая пара в проверке контраста; рамки 2,5 px, пунктир,
  тень-оттиск без размытия, без скруглений
- ✅ Шрифты: Oswald 600/700 (заголовки капсом, числа, печати) + Golos Text 400/600/700, шкала
  текста по макету (`theme/type.ts`); Manrope уходит вместе со старыми экранами
- ✅ Строки через ключи (`src/i18n`): тон «обычный / пацанский», формы множественного числа;
  ru сейчас, en / es на этапе 3
- Иконки: 16 штук из `B-Kit` (сетка 24, линия 2.5, острые углы) → SVG-компоненты; иконки
  привычек в том же стиле; волк-печать в трёх состояниях (в деле / злой / отдых)
- Базовые компоненты по `B-Kit` и экранам: шапка экрана (метка + заголовок), строка-чекбокс,
  печать (ЗАЧЁТ / ДОЛГ / СЛИВ / ВЫХ / ЗАКРЫТ / ДЕРЖИСЬ, поворот −12°…+8°), счёт палочками,
  неделя привычки (7 клеток), сегментный переключатель, переключатель, чипы, кнопка-оттиск,
  квадратная «+», шторка, таб-бар, тост с «Отменить»
- Каталог компонентов (экран в dev-сборке и вебе) для визуальной проверки в обеих темах

## ⏳ Этап 3. Новые экраны, настройки, языки

Навигация по макету: вкладки **Сегодня · Задачи · Привычки · Цели · Статы** («Отсчёт» уходит,
его заменяют цели со сроком); настройки открываются из шапки «Сегодня», итог дня — отдельный экран.

- Экраны по макетам: Сегодня, Задачи (группы «Долги / Сегодня / Завтра», свайп «вычеркнуть»),
  Привычки (неделя, вредные — «чистые дни»), Цели («договор»: зачёт, награда, «если слил»),
  Статы (удостоверение стаи, ранг, неделя), Новое дело (шторка), Итог дня, Настройки
- Настройки в профиле (синхронизируются): тема, чернила, тон, звания и очки, язык,
  начало недели, время итога дня; места и бэкап
- Звания (Щенок → Волчонок → Волк → Вожак → Альфа) и очки — чистая логика в `core` с тестами
- Локализация en / es для обоих тонов
- Отмена удаления (5 секунд), свайпы на gesture-handler, без лишних перерисовок
- Удаление старых экранов и слоя совместимости (`store/appStore.ts`, `core/legacy.ts`,
  `types/models.ts`, `theme/tokens.ts`)
- Иконка приложения и сплэш в стиле «Штамп» (волк-печать)

## ⏳ Этап 4. Напоминания по месту

- Места: точка на карте или «где я сейчас», радиус, вход / выход
- Геозоны через `expo-location` + `expo-task-manager` (фоновая геолокация)
- Экран-объяснение перед запросом разрешения «Всегда»
- Ограничения: iOS — до 20 зон, Android — до 100; только телефоны; нужна dev-сборка

## ⏳ Этап 5. ПК и веб

- Веб-сборка как PWA (установка из браузера, работа офлайн)
- Обёртка Tauri для Windows / macOS / Linux
- Раскладка под широкий экран, горячие клавиши

## ⏳ Этап 6. Синхронизация

- Supabase: авторизация (e-mail, Google, Apple), Postgres, правила доступа к строкам
- Синхронизация изменений по `updatedAt` (побеждает последнее), мягкие удаления
- Работа офлайн, очередь изменений, индикатор синхронизации
- Координаты мест по умолчанию не уходят в облако

## Принятые решения

| Решение                                                           | Почему                                                           |
| ----------------------------------------------------------------- | ---------------------------------------------------------------- |
| Остаёмся на Expo / React Native, без Flutter                      | Один код на Android, iOS и веб; переписывать на Dart нет смысла  |
| Local-first: данные на устройстве, синхронизация — отдельный слой | Работает офлайн; синхронизацию можно добавить без переделки ядра |
| Дизайн «Штамп»: бетон, чернила, печати, волк-печать               | Выбран из четырёх концептов; светлая и тёмная темы               |
| Контраст по WCAG обязателен для обеих тем                         | Проверяется скриптом в CI (`npm run check:contrast`)             |
| Языки ru / en / es                                                | По запросу                                                       |
