# Дорожная карта OpenStreak

Цель — релизная версия для **Android, iOS и ПК** с собственным дизайном «Мульт», двумя темами,
своим набором иконок, тремя языками и синхронизацией между устройствами.

Статусы: ✅ готово · 🔨 в работе · ⏳ впереди · 🗄 отложено в долгий ящик · ❓ ждёт решения

Порядок работ: **5 → 5б**. Этапы 6, 7 и 8 отложены: ПК/веб и синхронизация имеют смысл вместе, а
авторизация тянет за собой базу, безопасность и конфиденциальность — для такого приложения это спорно.

## ⏳ Этап 5. Напоминания по месту (приоритет)

- Карты в приложение не встраиваем (нет ключа и оплаты Google). Место = название, широта, долгота,
  радиус 100–2000 м, вход / выход. Способы задать точку:
  - «Я здесь» (координаты с телефона) — когда стоишь на месте
  - «Из карт»: открыть любое приложение карт, поделиться ссылкой или координатами, вставить в
    OpenStreak — разбираются Google, Яндекс, 2ГИС, OSM и пара чисел (короткие ссылки — нет)
  - ввод цифр руками; позже — поиск по адресу (Nominatim)
- Проверку «вошёл / вышел» делает ОС (геозоны), а не наш код; наш код выбирает, какие зоны ставить
- Геозоны через `expo-location` + `expo-task-manager` (фоновая геолокация)
- Экран-объяснение перед запросом разрешения «Всегда»
- Ограничения: iOS — до 20 зон, Android — до 100; только телефоны; нужна dev-сборка

## ⏳ Этап 5б. Серьёзный режим и сферы жизни

**Серьёзный режим** — вторая основная тема оформления рядом с «Мультом»: аккуратный, строгий дизайн
без шуток и без волка-персонажа; не шаблонный, но спокойный. Выбирается в настройках, у него свои
палитры (две темы, контраст по WCAG), шрифты и метрики.

- Макет на канвасе, утверждение на телефоне, затем код (как для «Луны» и «Мульта»)
- Токены, компоненты `src/ui`, иконки и каталог — в двух вариантах оформления; экраны не
  переписываются, меняется только оформление
- Тон текста: без цитат волка, званий-шуток и «пацанского» тона; нейтральные строки
- Игровое убрано полностью: нет очков, званий, луны дня, волка, цитат и «Стаи» как рейтинга; остаются
  дела, привычки с сериями, цели и итоги дня в нейтральном виде (числа, графики, без оценок-лун)

**Сферы жизни**

- Сейчас в интерфейсе нет создания сфер (в ядре `createArea` есть, экрана нет)
- Экран сфер: создать, переименовать, цвет и иконка, удалить; доступ из «Дел» и настроек
- Задача, привычка и цель создаются и без сферы — сфера необязательна и ничего не блокирует
- Из шторки «Новое» можно создать сферу на месте
- Пустое состояние «Дел» без сфер не должно мешать: дела просто идут общим списком

## Принятые решения

| Решение                                                                          | Почему                                                                             |
| -------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| Остаёмся на Expo / React Native, без Flutter                                     | Один код на Android, iOS и веб; переписывать на Dart нет смысла                    |
| Local-first: данные на устройстве, синхронизация — отдельный слой                | Работает офлайн; синхронизацию можно добавить без переделки ядра                   |
| Дизайн «Мульт»: наклейки, плашки под углом, луна дня, свой волк                  | Нейтральных трекеров много; «жизнь как игра» отличает, а логика остаётся серьёзной |
| Цвет со смыслом: жёлтый — луна и главное, бирюза — зачёт, красный — слив и долги | Весело, но не пёстро; цвет всегда что-то значит                                    |
| Наклон — только у украшений; текст и строки ровные                               | Читаемость важнее озорства                                                         |
| Свой волк, без героев и примет «Ну, погоди!»                                     | Берём дух эпохи, а не чужих персонажей                                             |
| Без «ИИ-примет»: капс, моно, антиква, градиенты                                  | Приложение не должно выглядеть шаблонным                                           |
| «Луна» и «Штамп» уходят в архив                                                  | «Штамп» громоздкий, «Луна» строгая; «Мульт» выбран после пробы                     |
| Макет сначала смотрим на телефоне, потом переносим в код                         | Иначе пропорции обманывают: на мониторе всё кажется меньше                         |
| Контраст по WCAG обязателен для обеих тем                                        | Проверяется скриптом в CI (`npm run check:contrast`)                               |
| Языки ru / en / es                                                               | По запросу                                                                         |
